Part 1 · Payments
Set Up Stripe
Stripe is the most trusted payment processor in the world. Setting it up takes about 15 minutes.
1

Create Your Free Stripe Account

Go to stripe.com and click "Start now". Sign up with your email. You'll need to verify your identity before accepting payments (takes 2–5 minutes — have your ID and bank details ready).

Open Stripe Sign Up →
💡Stripe pays out to your bank account on a 2-day rolling basis once you're verified.
2

Create a Product for Each Template

In your Stripe Dashboard, go to Products → Add product. Create one product per template. For each product:

💡For digital file delivery: after creating each product, go to Payment Links → Create link. Under the "After payment" tab, paste the direct URL to your template file on Netlify (e.g. https://novadeck.netlify.app/products/resume-pack.html). Stripe will show customers this URL after they pay.
3

Create a Payment Link (Buy Button) for Each Product

In Stripe, go to Payment Links → Create payment link. Select your product, set the price, then click Create link. You'll get a URL like https://buy.stripe.com/XXXXXXXX

Then go to Payment Links → ··· → Get embed code and copy the Buy Button code. It'll look like this:

<stripe-buy-button
  buy-button-id="buy_btn_XXXXXXXXX"
  publishable-key="pk_live_XXXXXXXXXXXX"
></stripe-buy-button>
⚠️Copy both the buy-button-id AND the publishable-key. You need both to make it work.
4

Add Your Stripe Links to the Store

Open novadeck-store.html in any text editor (Notepad, VS Code, etc.). Find this section near the bottom of the file:

stripeLink:"https://buy.stripe.com/REPLACE_WITH_YOUR_LINK_1"

Replace each REPLACE_WITH_YOUR_LINK_X with the actual Payment Link URL from Stripe for that product. Do this for all 8 products.

💡The Payment Link URL (e.g. https://buy.stripe.com/abc123) is simpler than the full embed code and works perfectly for the current store setup. When clicked, it opens Stripe's hosted checkout page.
